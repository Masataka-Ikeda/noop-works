ABOUT 自己紹介

事業会社で働きながら、Pythonを使ったデータ集計と業務効率化に取り組んでいます。日々の業務で発生する集計作業を自動化するところから始め、現在はPython 3 エンジニア認定データ分析試験に向けて、pandasやNumPyによるデータ処理を体系的に学んでいます。大事にしているのは、分析そのものよりも「その数字を見て何を決められるか」。受け取った人がすぐ動ける形まで落とし込むことを心がけています。

経歴・強み

  • 事業会社で実務を担当しながら、データ集計と業務効率化に取り組み中
  • Excelでの手作業集計をPythonに置き換え、月次レポートの作成を約3時間から20分に短縮
  • pandas / NumPy によるデータ整形・可視化。手順を残して誰でも再実行できる形で納品
  • Python 3 エンジニア認定データ分析試験に向けて学習中（受験予定）

SKILLS できること

  • 01

    データ集計の自動化

    Excelやスプレッドシートでの繰り返し作業を、Pythonスクリプトに置き換えます。毎月発生する手作業を、実行1回で終わる形に整理します。

  • 02

    データクレンジング

    表記ゆれ・欠損・重複が混ざったデータを、集計できる状態まで整えます。何をどう直したかの記録も合わせてお渡しします。

  • 03

    レポート / ダッシュボード作成

    集計結果をグラフと短い解説にまとめます。見た人がそのまま判断に使える形を目指します。

  • 04

    Excel / スプレッドシート改善

    関数やシート構成を見直し、壊れにくく引き継ぎやすいファイルに作り替えます。

  • 05

    生成AIを使った業務効率化

    定型の文書作成や情報整理にAIを組み込み、品質を保ったまま作業時間を減らす手順を設計します。

  • 06

    業務フローの棚卸し・ドキュメント化

    属人化している作業を洗い出し、手順書に落とします。担当が変わっても回る状態をつくります。

WORKS 実績紹介

データを集めるところから、繰り返し回せる仕組みにするところまで。
各工程での取り組みをまとめています。

  1. 01 COLLECT 集める 散らばったExcel・CSVをひとつに
  2. 02 CLEAN 整える 表記ゆれ・欠損・重複を処理
  3. 03 VISUALIZE 見える化 グラフと短い解説にまとめる
  4. 04 AUTOMATE 仕組み化 実行1回で回る形にする
